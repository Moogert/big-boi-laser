# Interface Text Review Checklist

For each operator message, answer these questions.

1. Does the text identify the exact system?
2. Does the text identify the exact state?
3. Does the text give one clear action?
4. Does the text state a prohibited action when necessary?
5. Does the text use an approved term?
6. Does the text fit the sentence-length rule?
7. Does the text avoid a generic confirmation?
8. Does the text avoid an unsupported safety claim?
9. Does the text distinguish a request from a confirmed result?
10. Does a qualified person need to approve the text?

A text checker cannot certify safety.

A qualified person must approve technical accuracy, hardware behavior, operator actions, severity, terminology, translation, and emergency procedures.
